使用须知

修改前了解这些
01

持久配置，不等于驱动支持

本工具写入持久的注册表地址覆盖，但无法强制驱动支持。部分 Intel Wi-Fi 网卡对地址修改有限制，写入可能不生效。永久地址为「—」表示驱动未提供，不能据此推断原始地址。

02

留意 Windows 随机硬件地址

请在 Windows 设置中手动关闭 Wi-Fi 全局及每个已保存网络（SSID）的随机硬件地址，以免系统覆盖预期地址。本工具不会替你改变这些开关。

03

连接可能短暂中断

应用、恢复默认或恢复上次配置可能临时断网，请先保存联网工作。原本禁用的网卡会保持禁用，待下次手动启用后验证；工具不会强制重启电脑，也不会为了应用地址而强制启用已禁用网卡。

04

偏移只检测，不自动修正

驱动升级、VPN 或系统随机地址功能可能重置覆盖。已存方案在重启后保留，但软件仅在运行时检测地址偏移，未安装开机任务。点击「载入目标」后仍需手动确认应用。

05

区分这几种地址

当前地址是系统报告的实际地址；永久地址来自驱动；注册表覆盖是已写入的配置；上次预期地址只在成功或待启用时更新。待应用地址是编辑草稿，保存方案和载入都不会写网卡。

06

失败与恢复

每次写入尝试都会保留记录。失败后可能自动回滚；若出现未完成操作，必须先恢复上次配置，才可继续修改。恢复默认会移除覆盖，但实际地址仍取决于驱动和 Windows 设置。恢复记录属于当前 Windows 用户；恢复前请确认未被其他用户或工具再次修改。
